# 📊 Global YouTube Stats Dashboard

An interactive Power BI dashboard analyzing global YouTube channel performance across content categories — built to explore trends in uploads, views, and subscribers using real-world-style data.

## 🔍 Overview

This project explores global YouTube channel statistics, uncovering patterns in content performance across categories like Music, Entertainment, Gaming, Education, and more. The report is split into 3 pages, each focused on a different angle of the data.

## 📌 Key Insights

- **9M** total uploads analyzed across global channels
- **165.73M** average video views per channel
- **301K** maximum uploads by a single channel
- Category-wise subscriber distribution — Music & Entertainment lead with 5B+ subscribers each
- Entertainment ranks highest overall at 124K, followed by Music (90K) and People & Blogs (71K)

## 📄 Report Pages

**Page 1 — Overview**
KPI cards (highest uploads, average views, min views), a radar chart comparing "Best View Rank" across categories, a table of total views by subscriber count, an upload trend line by channel title, and a bubble chart of subscribers by category.

**Page 2 — Rank Breakdown**
An interactive decomposition tree breaking down total category ranks, allowing drill-down from the overall sum into individual categories like Entertainment, Music, Gaming, and Education.

## 🛠️ Tools & Skills Used

- Interactive visuals: radar chart, decomposition tree, bubble chart, KPI cards
